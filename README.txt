BIT Keyboard — Android Studio project

This is a real Android Input Method (system keyboard), not just a mockup.
Design: deep charcoal-green background, muted grey-green text, pixel-like
monospace labels, thin borders, and compact keys (38dp high).

Build:
1. Open this folder in Android Studio.
2. Allow Gradle sync and install the Android SDK platform 35 if prompted.
3. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Install the generated APK on your Android phone.
5. Open BIT Keyboard and follow the Enable / Select steps.

The keyboard does not request internet access and does not collect or transmit
typed text. Android will display its standard warning when enabling any
third-party keyboard; review the app permissions and install only if you trust it.
